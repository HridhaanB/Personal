Divisibility rule for 6

We all know the classic divisibility rule for 6. Just combine the ones for 2 and 3. What if I told you that there was a specific divisibility rule for 6 that didn't involve checking all of its prime factors. 😱 Anyway, here is how it goes. If the units digit of a number plus quadruple the sum of the rest of the digits is divisible by 6, then the original number is divisible by 6.

Here, x is the place of the digit (units is 0, 10s is 1, 100s is 2, etc) and d is the digit. Lets say that there is a random number A that is divisible by 6.

We can say that A = 10x⋅dx + 10x-1⋅dx-1 + ⋅⋅⋅ + 10⋅d1 + d0.

This means that if A is divisible by 6, then A ≡ 0 mod 6.

Now, we must realize that 10 ≡ 4 mod 6, 102 ≡ 10⋅10 ≡ 4⋅4 ≡ 16 ≡ 4 mod 6.

Any further, and we must realize that any power of 10 with an integer exponent greater than 1 must be equivilent to 4 modulo 6 because with every additional factor of 10, you are multipying the last 4 by 4 to get 16, which is just 4 in mod 6. This means that we can say that A ≡ 4⋅(Σ dn) + d0, which is exactly what I said earlier. If the units digit plus 4 times the sum of the rest of the digits is divisible by 6, then the entire number is divisible by 6. QED

Actually, there is a bit of a problem with this proof, that only observant pendants will catch. An observent pendant is the worst kind of pendant. The problem is that I said that if A is divisible by 6, then the divisibility rule will work. However, for my divisibility rule to be a true divisibility rule, the statement needs to be a biconditional, ie. it should state that if and only if (iff) A is divisible by 6, then the divisibility trick works. Since we have proved the original conditional, we only need to prove its converse to prove the entire biconditional.

Now, we realize that if A ≡ 4⋅(Σ dn) + d0, then 4⋅(Σ dn) + d0 ≡ A, so the logic works in reverse. Now, QED
