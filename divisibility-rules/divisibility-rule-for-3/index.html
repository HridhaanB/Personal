Divisibility rule for 3

We all know the classic divisibility rule for 3. If the sum of all the digits is divisible by 3, then the entire number is divisible by 3. The proof of this is relatively simple, but I'm still going to walk you through it.

Here, x is the place of the digit (units is 0, 10s is 1, 100s is 2, etc) and d is the digit. Lets say that there is a random number A that is divisible by 3.

We can say that A = 10x⋅dx + 10x-1⋅dx-1 + ⋅⋅⋅ + 10⋅d1 + d0.

This means that if A is divisible by 3, then A ≡ 0 mod 3.

Now, we must realize that any power of 10 is equivilent to 1 mod 3, so A ≡ Σ dn mod 3, so if the sum of the digits is divisible 3, then the original number is divisible by 3.

This means that we can say that A ≡ d0, which is exactly what I said earlier. QED

Actually, there is a bit of a problem with this proof, that only observant pendants will catch. An observent pendant is the worst kind of pendant. The problem is that I said that if A is divisible by 3, then the divisibility rule will work. However, for my divisibility rule to be a true divisibility rule, the statement needs to be a biconditional, ie. it should state that if and only if (iff) A is divisible by 3, then the divisibility trick works. Since we have proved the original conditional, we only need to prove its converse to prove the entire biconditional.
