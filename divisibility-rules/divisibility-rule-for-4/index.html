Divisibility rule for 4

We all know the classic divisibility rule for 4. If the last two digits are divisible by 4, then the entire number is divisible by 4. For example, 124 is divisible by 4 because 24 is divisible by 4. The proof of this is relatively simple, but I'm still going to walk you through it and even expand this rule.

Here, x is the place of the digit (units is 0, 10s is 1, 100s is 2, etc) and d is the digit. Lets say that there is a random number A that is divisible by 4.

We can say that A = 10x⋅dx + 10x-1⋅dx-1 + ⋅⋅⋅ + 10⋅d1 + d0.

Any multiple of 100 is divisible by 4, so we get that if A is divisible by 4, then A ≡ 10⋅d1 + d0 mod 4. This is the common rule.

Now, we must realize that 10 ≡ 2 mod 4, so we can say that A ≡ 2*d1 + d0. QED

Actually, there is a bit of a problem with this proof, that only observant pendants will catch. An observent pendant is the worst kind of pendant. The problem is that I said that if A is divisible by 4, then the divisibility rule will work. However, for my divisibility rule to be a true divisibility rule, the statement needs to be a biconditional, ie. it should state that if and only if (iff) A is divisible by 4, then the divisibility trick works. Since we have proved the original conditional, we only need to prove its converse to prove the entire biconditional.
