MOD TIME!

Here, I will be using modular arithmetic rule to prove common and uncommon divisibility rules. The general process is that you write a number in the form $10^x\cdot d_x + 10^{x-1}\cdot d_{x-1} + \cdots + 10\cdot d_1 + d_0$ reduce all the powers of 10 into their residue mod whatever number's divisibility rule that you're checking. You then take the result and simplify it. See below for examples.

This means that any number can have a divisibility rule. More formally, to check a number A is divisible by another number N if and only if it is N evenly divides another number less than or equal to A. This even works in other bases.
